# Govardhans macOS Desktop

A pixel-faithful React recreation of the macOS desktop from Figma, ready to deploy on Vercel.

## Features
- macOS-style menu bar with live clock
- Animated dock with magnification on hover
- Spotlight-style search bar
- Desktop icon (govardhans resume) with click interaction
- macOS wallpaper gradient recreation

## Deploy to Vercel

### Option 1: Vercel CLI
```bash
npm install -g vercel
npm install
vercel
```

### Option 2: GitHub + Vercel Dashboard
1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → New Project
3. Import your GitHub repo
4. Vercel auto-detects Create React App — just click **Deploy**

### Option 3: Drag & Drop
1. Run `npm run build` locally
2. Drag the `build/` folder to [vercel.com/new](https://vercel.com/new)

## Local Development
```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)
